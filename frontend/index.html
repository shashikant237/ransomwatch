Faculty Guide & Technical Reference

Plain-English explanations, academic concepts, and demonstration guide for evaluators.

🔒

What is Ransomware?

Malicious software that secretly encrypts your files (like documents, photos, and databases) and demands payment in cryptocurrency to unlock them.

👁️

What is Behaviour Monitoring?

Watching what running programs are actually doing (e.g. how many files they rename or overwrite per second) rather than just looking at file names or signatures.

📈

What is Anomaly Detection?

Using machine learning to learn what "normal computer work" looks like, and immediately alerting when a program behaves abnormally.

🎲

What is Shannon Entropy?

A mathematical measure of how random data is. Plain text has low entropy (~3.5). Encrypted files look completely random with very high entropy (~7.9).

🤖

What is Machine Learning here?

We use Isolation Forest for runtime anomaly detection and Random Forest to check executable files for dangerous structures before they run.

🎯

What is a Risk Score?

A combined score from 0 to 100 showing how dangerous a process appears, based on rules and machine learning working together.
