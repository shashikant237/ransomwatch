System Architecture & Evaluation Guide

Technical reference, core defensive concepts, and evaluation guide for academic assessment.

Ransomware Threat Model

Malicious payloads designed to recursively traverse local/network shares, encrypt high-value user files using symmetric/asymmetric cipher suites, and demand cryptocurrency extortion.

Runtime Behavioural Telemetry

Continuous dynamic instrumentation of process operations (file I/O velocity, rename loops, directory depth) to detect unauthorized cryptographic conversions in real time.

Unsupervised Anomaly Detection

Isolation Forest algorithm partitions multidimensional feature spaces using binary isolation trees, identifying statistical outliers without requiring prior malware signatures.

Shannon Entropy Analysis

Measures bitwise information density (\(0.0\) to \(8.0\text{ bits/byte}\)). Plaintext displays low entropy (\(\sim 3.5\)), while encrypted payloads approach theoretical maximum (\(\sim 7.9\)).

Portable Executable (PE) Forensics

Static inspection of Windows PE headers: section distributions, debug directory stripping, DLL characteristic memory flags (DEP/ASLR), and cryptocurrency wallet address strings.

Composite Risk Scoring

Combines rule-based deterministic weights with calibrated machine learning anomaly probabilities into a single, explainable 0–100 index for automated SOC response.
